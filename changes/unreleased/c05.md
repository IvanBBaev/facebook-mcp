### Added

- **Stable insights schema (groundwork).** The server now owns a map of stable insights keys (`views`, `viewers`, `engagements`, `followers`, `follows`, `unfollows`, `page_views`, `clicks`, `reactions`, `video_views`, `plays`, …) for Page, post and Reel reads. Each key is mapped to the Graph metric it is read from, and gets a per-read status of `ok`, `empty` or `removed`, so a future Meta metric rename or removal becomes a status change rather than a breaking change. The insights tools adopt it in a later step; no tool output changes yet. See `docs/insights-schema.md`.
