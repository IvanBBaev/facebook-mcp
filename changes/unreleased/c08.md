### Security

- **Outbound writes need out-of-band confirmation once untrusted content has entered the session (SEC-01).** The server now keeps a session taint latch: the first tool result that carries untrusted Page content (a comment, a message, a post body — anything wrapped in the untrusted-content envelope) sets it, and it is never cleared for the life of the server process. From then on, a write marked `outbound` (one that speaks for the Page: a DM, a public reply, publish-now and so on) is plan-bound and must be confirmed by a human — by elicitation or the `FB_CONFIRM_TOKEN` operator token — whatever its tier, and its preview says so. Writes not marked outbound, and every write in a session that has not read untrusted content, behave exactly as before. The gate fails closed: a gate built without the latch treats every session as tainted. This release adds the mechanism only; the individual tools opt in with `outbound: true` in a follow-up, so no tool changes behaviour yet.
- **A write whose arguments carry a credential is refused (SEC-06).** Before any plan or apply, the shared write path checks every field of the outbound payload for a configured secret (access, system, Page or per-profile token, app secret, app token, HTTP token, confirm token — in any URL-, form- or JSON-encoded form) or an `EAA…`/`{app-id}|{app-secret}`-shaped token, and refuses with `code: "secret_in_payload"`, naming the field and never the value. Bare hex strings such as an ad `image_hash` are not treated as secrets.
- **Open owner questions (C08, fail-closed defaults taken):** (1) the latch is per server process, so on the HTTP transport one client reading untrusted content latches every later session — confirm whether it should be per MCP session; (2) outbound tools that do not already accept `confirm_token` can only be confirmed by elicitation, so lanes opting a tool in should spread `confirmableWriteArgs`; (3) the latch also sets on server text that merely quotes the untrusted-content markers, which over-confirms but never under-confirms.
