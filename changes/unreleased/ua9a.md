### Changed

- **BREAKING: `facebook_boost_post` requires `special_ad_category: "none"`.** The argument is the operator's attestation that the ad is not about housing, employment, credit, or social issues / elections / politics. Scripts that call `facebook_boost_post` must add it. Without it the call is refused with an error that says what to pass; any other value (for example `"housing"`) is refused because this server does not support special-category ads. Those ads must be created in Ads Manager. The preview shows the attestation, and the value is bound to the plan, so a `plan_id` from a preview cannot be applied with a different or missing attestation. Boost plans previewed before this change cannot be applied; preview again.
- **The `facebook_boost_post` preview states that Meta's AI features are off.** It lists Advantage+ audience off (`advantage_audience: 0`) and every creative enhancement `OPT_OUT`. The created objects already sent these values; tests now assert the full payload.
- **The `facebook_duplicate_ad_object` preview warns that the copy inherits the source's Advantage+ / creative-enhancement settings.** The server does not change them, so check them in Ads Manager before activating the copy.
- **Every ads write tool states the Self-Serve Ad Terms.** The descriptions of `facebook_update_ad_object`, `facebook_archive_ad_object`, `facebook_delete_ad_object`, `facebook_upload_ad_image`, `facebook_update_ad_set_targeting`, `facebook_duplicate_ad_object` and `facebook_boost_post` end with: "Changes are made in the operator's ad account under Meta's Self-Serve Ad Terms; the operator is billed and responsible for the result."
