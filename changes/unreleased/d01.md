### Changed

- **The README now states only what is true for 0.8.** It no longer lists shipped tools (Stories, albums and photos, Page profile edits) as out of scope; it separates tools that ship as **experimental** (ads writes beyond status and budget, Messenger labels, reactions and attachments, Page profile edits) from things that are not planned. The roadmap uses the current release labels (0.9 contracts, 1.0 "verified Pages core", 2.0 removals) instead of the old milestones, and says plainly that nothing has been verified against a live Page and that the plugin install route has not been walked end-to-end. The operator section now says that ads made through this server are the operator's contract with Meta, that `facebook_boost_post` always declares no special ad category, and that from 2026-11-20 Meta's Self-Serve Ad Terms make the operator responsible for third-party software such as this server. The competitor survey is re-dated to 2026-10-29.
