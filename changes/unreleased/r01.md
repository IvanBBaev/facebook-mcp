### Added

- **`facebook_get_ad_set_targeting` reports `advantage_audience_state`** (`on`, `off` or `unset`) in its summary. `unset` means the ad set never stored the setting, and from Graph v23 Meta may treat that as on. The existing `advantage_audience` field is unchanged.

### Fixed

- **`facebook_update_ad_set_targeting` can no longer silently turn Advantage+ audience on.** When the ad set's targeting does not carry `targeting_automation.advantage_audience`, the edit now writes it explicitly as `0` (other `targeting_automation` keys are kept), and the preview says "Advantage+ audience: set explicitly OFF (was unset)". Before, the blob went back without the field, and on Graph v23+ Meta could default it to on, so ads delivered outside the countries and ages just set, or the edit failed with error 100.
- **`facebook_duplicate_ad_object` flags copies that came back with Advantage+ audience on.** After the copy, each copied ad set's Advantage+ audience is read back next to its source's. A copy that is on where the source was off or unset is listed in `advantageAudience.expanded` and named in the result's `alert`, so it can be turned off before the copy is activated. A copy whose setting could not be read is named too.
