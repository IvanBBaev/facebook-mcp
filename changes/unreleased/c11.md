### Security

- **A write tool can no longer reach the gate below its published tier (QA-07).** Each tool's declared `writeTier` (the tier column in the README) is now the single source of truth: the write gate refuses, before anything is planned or performed, a call whose handler hands it a tier from a lower gate class or above the declared worst case. A copy-paste mis-tier can therefore never make an `irreversible` or `spend` write coverable by `FB_WRITE_MODE=apply`. No tool's behaviour or tier changes.
