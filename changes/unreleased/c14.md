### Added

- **The write journal now ages out old entries.** Entries older than
  `FB_JOURNAL_RETENTION_DAYS` days (default 90; `0` = no age limit) are dropped at the
  first write after start-up, once a day and on rotation, so a quiet Page no longer keeps recipient
  PSIDs for years. The live file is only ever rotated, never rewritten in place, and
  a failed pass is a stderr note that never costs a journal entry. `PRIVACY.md`
  describes the new retention.
