### Added

- **Multiple-token warning.** Setting more than one of `FB_SYSTEM_TOKEN`, `FB_ACCESS_TOKEN` and `FB_PAGE_TOKEN` now warns at startup and in `doctor` (`multiple-tokens`), naming the one that is used (precedence system > access > page) and the ones that are ignored. Only names are reported, never values.

### Deprecated

- **Renamed environment variables.** `FB_PACKAGES_DENY` is now `FB_TOOL_PACKAGES_DENY`, `FB_PACKAGES_READONLY` is now `FB_TOOL_PACKAGES_READONLY`, and `FB_HTTP_TOKEN` is now `FB_HTTP_BEARER`. The old names are still read throughout 1.x, with a `deprecated-setting` warning at startup and in `doctor`; 2.0 stops reading them. Setting an old and a new name to different values is a startup error (`setting-alias-conflict`). See "Renamed variables" in the README.
